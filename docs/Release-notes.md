# GPOCasebook 0.2.0

- Opens directly to the workbench for local collection, imports, or domain scans.
- Adds Help and an About dialog with the version, author, project link, and MIT license.
- Discovers enabled Active Directory computers and reads Group Policy evidence from selected systems.
- Lets Windows prompt for an alternate network identity for domain collection.
- Archives each available capture and saves a domain scan summary with per-computer outcomes.
- Continues to open archives from earlier releases and adds a Windows 11 x64 MSIX build for Microsoft Store submission.

Download GPOCasebook-Setup.exe for the classic per-user installation. The
README explains collection, imports, and archive management.
