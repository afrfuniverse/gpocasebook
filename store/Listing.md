# GPOCasebook

## Short description

Collect, compare, and archive Windows Group Policy evidence for individual PCs
and Active Directory domains.

## Description

GPOCasebook helps you investigate Windows Group Policy processing. Collect
evidence from this PC, import exported Windows logs and RSoP files, or select
computers from an Active Directory domain. See event timelines and recorded
policy outcomes, then compare two captures before and after a change.

Search and reopen local archives. Export HTML summaries for sharing or
detailed reports for internal review. Domain scans record which sources each
computer returned and save the evidence available from each computer.

Requires Windows 11 x64. Domain scans use existing Windows credentials and
require access to the selected Active Directory and Windows log sources.

## Features

- Group Policy timeline with Windows event details
- Local collection and EVTX, XML, and RSoP imports
- Read-only Active Directory computer discovery and selected PC collection
- Searchable local archive and before-and-after comparison
- HTML capture reports and internal domain scan summaries
